01 Decision Tree — ID3 & Information Gain

1. Concept

  • A Decision Tree is a supervised learning model that classifies data by recursively splitting it based on attribute values, forming a tree of decision nodes (tests) and leaf nodes (class labels). It's popular because it's easy to interpret and convert into if-then rules.
  • ID3 (Iterative Dichotomiser 3) builds the tree top-down, greedily, choosing at each node the attribute that best separates the classes using Information Gain as the selection measure.

2. Key Formulas

Entropy — impurity measure Entropy(S) = −Σ pᵢ log₂(pᵢ)

where pᵢ = proportion of class i in set S.

Information Gain for attribute A Gain(S, A) = Entropy(S) − Σ (|Sᵥ|/|S|) × Entropy(Sᵥ)

— the reduction in entropy after splitting on A.

3. ID3 Algorithm Steps

  • Compute Entropy(S) of the entire dataset using the target class distribution.
  • For each candidate attribute, compute weighted entropy of its subsets and derive its Information Gain.
  • Select the attribute with the highest Information Gain as the root/splitting node.
  • Recursively repeat on each branch's subset until a node is pure (single class) or no attributes remain — these become leaf nodes.

(maximum impurity, perfect 50-50 split).

Step 2 — Entropy & Gain for "Age"

  • Old(3): all Down → Entropy = 0. New(3): all Up → Entropy = 0. Mid(4): 2 Up, 2 Down → Entropy = 1.
  • Weighted Entropy = (3/10)(0) + (4/10)(1) + (3/10)(0) = 0.4 → Gain(Age) = 1 − 0.4 = 0.6.

Step 3 — Entropy & Gain for "Competition"

  • Yes(4): 3 Down, 1 Up → Entropy ≈ 0.811. No(6): 2 Down, 4 Up → Entropy ≈ 0.918.
  • Weighted Entropy = (4/10)(0.811)+(6/10)(0.918) ≈ 0.875 → Gain(Competition) ≈ 0.125.

Step 4 — Entropy & Gain for "Type"

  • Software(6): 3 Down, 3 Up → Entropy = 1. Hardware(4): 2 Down, 2 Up → Entropy = 1.
  • Weighted Entropy = 1 → Gain(Type) = 1 − 1 = 0 (no information gained — useless split).

5. Root Node Selection

  • Comparing: Gain(Age) = 0.6 > Gain(Competition) = 0.125 > Gain(Type) = 0.
  • Since Age gives the highest Information Gain, it is chosen as the root node. "Old" and "New" branches become pure leaves (Down, Up respectively); only the "Mid" branch needs further splitting using the remaining attributes (Competition/Type).
Quick revision box
  • High Entropy = more disorder/impurity → bad split. High Gain = attribute separates classes well → good split.
  • ID3 = greedy + recursive + top-down, always picks max Gain attribute first; stops when node is pure or attributes exhausted.
  • Limitation to mention for extra marks: ID3 is biased toward attributes with many values — this is fixed in C4.5 using Gain Ratio instead of plain Information Gain.

02 Logistic Regression — Linear Classification

Appeared in nearly every paper — sometimes Part A, sometimes a full 6–14 mark question.

1. Concept

  • Logistic Regression is a supervised algorithm used for classification (despite the name "regression"), typically binary classification (classes 0/1). It models the probability that a given input belongs to a particular class, rather than predicting the class directly.
  • It is called a linear classifier because it computes a linear combination of input features — the decision boundary it produces is a straight line/hyperplane in feature space.

2. Why Not Linear Regression for Classification?

  • Linear Regression outputs values over an unbounded range (−∞ to +∞), which is unsuitable since probabilities must lie between 0 and 1.
  • It is also highly sensitive to outliers and can produce nonsensical predictions (e.g., negative probability) — this motivates the need for a squashing function.

3. The Sigmoid (Logistic) Function

  • Logistic Regression passes the linear combination z = w₀ + w₁x₁ + w₂x₂ + ... + wₙxₙ through the sigmoid function:
Sigmoid σ(z) = 1 / (1 + e−z)
  • The sigmoid squashes any real-valued input into the range (0, 1), making the output interpretable as a probability P(y=1|x). The curve is S-shaped, symmetric about z = 0 where σ(z) = 0.5.

4. Decision Rule

  • Once probability P(y=1|x) = σ(z) is computed, a threshold (commonly 0.5) is applied:
  • If P ≥ 0.5 → predict Class 1; if P < 0.5 → predict Class 0. This threshold corresponds to z = 0, which defines the linear decision boundary separating the two classes.

5. Cost Function — Why Not MSE?

  • Using Mean Squared Error with sigmoid makes the cost function non-convex (many local minima), so Gradient Descent may fail to find the global minimum.
  • Instead, Logistic Regression uses Log Loss / Cross-Entropy Loss:
Cross-entropy cost Cost = −[ y·log(ŷ) + (1−y)·log(1−ŷ) ]
  • This cost function is convex, heavily penalizes confident wrong predictions, and guarantees Gradient Descent converges to the global minimum.

6. Parameter Learning

  • Weights w are learned by minimizing the cost function (average cross-entropy over all training examples) using Gradient Descent:
Weight update wⱼ := wⱼ − α · ∂Cost/∂wⱼ
  • Here α (alpha) is the learning rate, controlling the step size of each update; this is repeated iteratively until the cost converges.

7. Diagram to Draw

  • Sketch the S-shaped sigmoid curve (x-axis: z, y-axis: σ(z) from 0 to 1), marking the 0.5 threshold line at z=0 — this single diagram is often worth separate marks.
Quick revision box
  • Linear part → z = wᵏxᵏ (combination) → Sigmoid → squashes to probability → Threshold (0.5) → class label.
  • Keywords to drop for marks: linear decision boundary, Maximum Likelihood Estimation (alternate way cost function is derived), convex cost function, binary classifier.
  • Contrast line (common Part A ask): "Linear Regression predicts continuous values; Logistic Regression predicts class probabilities."

03 Overfitting — Causes & Prevention

1. Concept

  • Overfitting occurs when a model learns the training data too well, capturing not just the underlying pattern but also the noise and random fluctuations specific to that dataset.
  • Such a model shows high accuracy on training data but poor generalization/performance on unseen test data — the gap between train and test error is the classic symptom.

2. How It Occurs — Root Causes

  • Excessive model complexity: using a model with too many parameters/features (e.g., a very deep decision tree or a high-degree polynomial) relative to the amount of data — the model has enough "freedom" to memorize training points instead of learning general trends.
  • Insufficient training data: when the dataset is small, the model cannot distinguish genuine patterns from random noise, so it fits the noise too.
  • Training for too long / too many iterations: in iterative algorithms (e.g., gradient descent, neural nets), training beyond the optimal point causes the model to start fitting noise rather than signal.
  • Noisy or irrelevant features: including redundant or unrelated attributes gives the model extra ways to latch onto spurious correlations.

3. Bias-Variance Connection

  • Overfitting corresponds to low bias, high variance — the model is too flexible, so small changes in training data cause large changes in the learned function. This is the direct opposite of underfitting (high bias, low variance), where the model is too simple to capture the pattern at all.

4. Detecting Overfitting

  • Plot a learning curve: training error keeps decreasing while validation/test error starts increasing after a point — this diverging gap is the clearest diagnostic sign.

5. Methods to Prevent Overfitting

  • Cross-Validation: use k-fold cross-validation to evaluate the model on multiple train-test splits, ensuring performance generalizes rather than depending on one lucky split.
  • Regularization (L1/Lasso and L2/Ridge): add a penalty term to the cost function that discourages large weight values, forcing the model toward simpler solutions.
Regularized cost Cost = Loss + λ·Σ|w|  (L1)  |  Cost = Loss + λ·Σw²  (L2)
  • where λ (lambda) controls penalty strength.
  • Pruning (for Decision Trees): remove branches that have little predictive power, either by pre-pruning (stop growth early) or post-pruning (grow fully, then trim back).
  • Early Stopping: halt training as soon as validation error starts increasing, even if training error is still falling — prevents the model from over-memorizing.
  • Dropout (for Neural Networks): randomly deactivate a fraction of neurons during each training iteration, forcing the network to learn redundant, robust representations instead of relying on specific neurons.
  • Increasing Training Data: more diverse, representative data helps the model learn genuine patterns and dilutes the influence of noise.
  • Feature Selection/Reduction: remove irrelevant or redundant features (or use dimensionality reduction like PCA) to simplify the hypothesis space.
  • Ensemble Methods (e.g., Random Forest, Bagging): combine multiple models to average out individual overfitting tendencies, improving generalization.
Quick revision box
  • One-line definition to open with: "Overfitting = low training error + high test error, caused by excessive model complexity relative to data."
  • Memory hook for prevention methods: "CROP-DIE" → Cross-validation, Regularization, Oversized data (more data), Pruning, Dropout, Early stopping — pick any 5-6 to write for full marks.
  • Always pair with underfitting as contrast if asked generally: "Underfitting → model too simple, high bias; Overfitting → model too complex, high variance."

04 Information Gain & Gini Index

1. Concept — Why We Need Them

  • Both are attribute selection measures used in Decision Tree construction to decide which attribute to split on at each node — the goal is to choose the attribute that produces the purest possible child nodes.
  • Information Gain (used in ID3) is based on Entropy; Gini Index (used in CART) is an alternative impurity measure that is computationally simpler (avoids log calculations).

2. Entropy — Foundation for Information Gain

  • Entropy measures the impurity/disorder of a dataset with respect to class labels:
Entropy Entropy(S) = −Σ pᵢ log₂(pᵢ)
  • Entropy = 0 when the set is perfectly pure (all one class); Entropy = 1 (max) when classes are equally split (50-50 for binary classes).

3. Information Gain — Definition & Formula

  • Information Gain (IG) measures the reduction in entropy achieved by splitting a dataset on a particular attribute A:
Information gain Gain(S, A) = Entropy(S) − Σ (|Sᵥ|/|S|) × Entropy(Sᵥ)
  • The second term is the weighted average entropy of the subsets Sᵥ created by splitting on A. The attribute with the highest Information Gain is chosen as the splitting node.

4. Gini Index — Definition & Formula

  • Gini Index measures the probability of misclassifying a randomly chosen element if it were randomly labeled according to the class distribution in the subset:
Gini index Gini(S) = 1 − Σ pᵢ²
  • Gini = 0 for a pure node; Gini = 0.5 (max for binary classes) when classes are equally mixed. For a split, compute the weighted Gini of children:
Weighted Gini of a split Gini_split = Σ (|Sᵥ|/|S|) × Gini(Sᵥ)
  • Unlike Information Gain (pick highest), for Gini Index we pick the attribute/split with the lowest weighted Gini Index.

5. Worked Example (Generic Binary Dataset)

Suppose a dataset S has 10 instances: 6 "Yes", 4 "No". Splitting on attribute A gives two subsets: A=1 (5 instances: 4 Yes, 1 No) and A=0 (5 instances: 2 Yes, 3 No).

Entropy(S) = −(6/10)log₂(6/10) − (4/10)log₂(4/10) ≈ 0.971
Entropy(A=1) = −(4/5)log₂(4/5) − (1/5)log₂(1/5) ≈ 0.722
Entropy(A=0) = −(2/5)log₂(2/5) − (3/5)log₂(3/5) ≈ 0.971
Weighted Entropy = (5/10)(0.722) + (5/10)(0.971) ≈ 0.847
Gain(S, A) = 0.971 − 0.847 = 0.124
Gini(S) = 1 − [(6/10)² + (4/10)²] = 1 − 0.52 = 0.48
Gini(A=1) = 1 − [(4/5)² + (1/5)²] = 1 − 0.68 = 0.32
Gini(A=0) = 1 − [(2/5)² + (3/5)²] = 1 − 0.52 = 0.48
Weighted Gini = (5/10)(0.32) + (5/10)(0.48) = 0.40
Gini Gain = Gini(S) − Gini_split = 0.48 − 0.40 = 0.08

(improvement — lower weighted Gini = better split)

  • One-liner: "Entropy/Gini measure impurity; Information Gain/Gini Gain measure the reduction in impurity after a split — higher Gain or lower Gini wins the split."
  • Formula pair to memorize together: Entropy uses log₂(p), Gini uses p² — this single distinction answers most "difference between" Part-A questions.

05 Linear Regression

1. Concept

  • Linear Regression is a supervised learning algorithm used to model the relationship between a dependent variable (y) and one or more independent variables (x) by fitting a straight line through the data.
  • It is primarily used for prediction of continuous numerical values (e.g., price, premium, salary) — unlike classification, the output is not a class label but a real number.

2. Types

  • Simple Linear Regression: involves one independent variable — models y = b₀ + b₁x.
  • Multiple Linear Regression: involves two or more independent variables — models y = b₀ + b₁x₁ + b₂x₂ + ... + bₙxₙ.

3. The Regression Line Equation

Fitted line ŷ = b₀ + b₁x
  • b₀ (intercept) = value of y when x = 0.
  • b₁ (slope/coefficient) = change in y for a unit change in x — indicates the strength and direction of the relationship.
  • The goal is to find the "best fit line" that minimizes the overall prediction error across all data points.

4. Cost Function — Least Squares Method

  • Linear Regression uses Mean Squared Error (MSE) as its cost function:
MSE cost Cost = (1/n) Σ(yᵢ − ŷᵢ)²
  • Minimizing this sum of squared residuals is called the Ordinary Least Squares (OLS) method — it penalizes larger errors more heavily (due to squaring) and gives a unique, closed-form solution.

5. Formulas for b₀ and b₁ (Least Squares)

Slope b₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²
Intercept b₀ = ȳ − b₁x̄
  • Here x̄ and ȳ are the means of x and y respectively — these two formulas are the core computation for any numerical.

  • R² (Coefficient of Determination): measures the proportion of variance in y explained by x, ranges from 0 to 1 — closer to 1 = better fit.
  • RMSE (Root Mean Squared Error): square root of MSE, expressed in the same units as y, giving an interpretable error magnitude.
Quick revision box
  • Sequence to always follow in numericals: means → deviations → Σ(xy) and Σ(x²) → b₁ → b₀ → equation → predict, this exact order earns step-marks even with calculation errors.
  • One-liner for Part A: "Linear Regression fits a straight line ŷ = b₀ + b₁x by minimizing the sum of squared errors (Least Squares Method)."
  • Common confusion to clarify: slope (b₁) = rate of change; intercept (b₀) = baseline value — examiners often ask to interpret these separately for extra marks.

06 Classification vs Regression

1. Concept

  • Both are types of Supervised Learning, where the model learns from labeled training data (input-output pairs) to make predictions — the key difference lies in the nature of the output variable.
  • Classification predicts a discrete/categorical label (which class an input belongs to), while Regression predicts a continuous numerical value.

2. Core Definitions

  • Classification: maps input features to one of a finite set of predefined classes/categories (e.g., Spam/Not Spam, Yes/No, Disease/No Disease).
  • Regression: maps input features to a real-valued continuous output (e.g., price, temperature, salary) — there is no fixed set of categories, output can take infinitely many values.

3. Output Type

  • Classification → Discrete/Qualitative output (class labels, can be binary like 0/1 or multi-class like A/B/C).
  • Regression → Continuous/Quantitative output (any real number within a range).

4. Examples

  • Classification: email spam detection, disease diagnosis (positive/negative), credit approval (approve/reject), handwritten digit recognition.
  • Regression: predicting house prices, insurance premium estimation, stock price forecasting, predicting a student's exam score.

5. Algorithms Used

  • Classification: Logistic Regression, Decision Trees, k-NN, Naive Bayes, SVM.
  • Regression: Linear Regression, Polynomial Regression, Ridge/Lasso Regression (note: some algorithms like Decision Trees and k-NN can be adapted for both tasks).

6. Evaluation Metrics high-value point

  • Classification is evaluated using: Accuracy, Precision, Recall, F1-Score, Confusion Matrix, ROC-AUC.
  • Regression is evaluated using: MSE (Mean Squared Error), RMSE, MAE (Mean Absolute Error), R² (Coefficient of Determination) — these measure distance/error rather than correctness of label.

7. Decision Boundary vs Fitted Line

  • Classification models learn a decision boundary (a line/curve/hyperplane) that separates classes in feature space.
  • Regression models learn a best-fit line/curve that passes through or close to the data points to approximate the trend.

07 Univariate vs Multivariate Linear Regression

1. Concept

  • Both are Linear Regression variants used to predict a continuous dependent variable (y) — they differ only in the number of independent variables (features) used as predictors.
  • Univariate uses one input feature; Multivariate (also called Multiple Linear Regression) uses two or more input features simultaneously.

2. Definitions & Equations

  • Univariate Linear Regression: models the relationship between a single independent variable x and dependent variable y using a straight line:
ŷ = b₀ + b₁x
  • Multivariate Linear Regression: models y as a function of multiple independent variables x₁, x₂, ..., xₙ, fitting a hyperplane instead of a line:
ŷ = b₀ + b₁x₁ + b₂x₂ + ... + bₙxₙ

3. Geometric Interpretation

  • Univariate: the fitted model is a 2D straight line (plotted on x-y axes).
  • Multivariate: the fitted model is a hyperplane in n-dimensional space — with 2 features it's a 3D plane, beyond that it's not visually plottable but mathematically extends the same way.

4. Coefficients — Interpretation

  • Univariate: b₁ represents the change in y for a unit change in the single x.
  • Multivariate: each bᵢ represents the change in y for a unit change in xᵢ, while holding all other variables constant — this "holding constant" nuance is a key exam point often missed.

5. Complexity & Computation

  • Univariate is computationally simple — slope and intercept can be found with basic Least Squares formulas directly.
  • Multivariate requires matrix algebra:
Normal equation B = (XᵀX)⁻¹XᵀY
  • where X is the design matrix of input features and B is the vector of coefficients — this is computationally heavier and often solved via Gradient Descent for large feature sets.

6. Additional Considerations Unique to Multivariate

  • Multicollinearity: a problem exclusive to multivariate regression — occurs when independent variables are correlated with each other, making coefficient estimates unstable/unreliable. Checked using VIF (Variance Inflation Factor).
  • Feature Selection/Dimensionality: with many features, multivariate regression risks overfitting, requiring techniques like regularization (Ridge/Lasso) or feature selection — not a concern in univariate regression.

7. Examples

  • Univariate: predicting insurance premium using only driving experience.
  • Multivariate: predicting house price using area, number of bedrooms, location, and age of property together.
