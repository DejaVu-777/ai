The buttons only work if aim1.html – aim5.html sit in the very same folder as this file, with those exact names. If it still won't open — check these

  1. Same folder. index.html and aim1.html must be in one folder — not one in Downloads and the other in Documents.
  2. Exact name. The link asks for aim1.html. A file saved as aim1 (1).html, aim1.htm or Aim1.html won't match — rename it to aim1.html exactly.
  3. Don't open it from inside a zip, email preview or chat app. Extract the folder to your device first, then open index.html from the file manager.
  4. On Android: if a file manager opens the HTML as text, open it in Chrome instead — long-press the file → Open with → Chrome.
