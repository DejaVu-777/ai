01 Modus Ponens & Modus Tollens

Note on this set: the topic heading that came with these notes was the resolution proof on a knowledge base ("Col. West is a criminal" and its variants — Gita/almond, John/peanuts, graduating/happy/smiling). The answer body here is Modus Ponens and Modus Tollens, so the FOL → CNF → resolution proof itself is not in this paste and is not on this page.

Both are fundamental rules of inference in Propositional and First Order Logic, used to derive new true conclusions from existing true premises. They form the logical basis of forward chaining (Modus Ponens) and backward/refutation-style reasoning (Modus Tollens).

1. Modus Ponens ("Mode that affirms")

  • Rule form: Given P → Q (if P then Q) and P (P is true), we can conclude Q (Q is true).
Symbolic notation P → Q ,  P  ∴  Q
  • It is the most commonly used inference rule, forming the basis of forward chaining in expert systems and rule-based reasoning — facts trigger rule conclusions.
  • Generalized Modus Ponens (FOL version): used with unification, e.g., ∀x King(x) ∧ Greedy(x) → Evil(x), King(John), Greedy(John) ⟹ Evil(John).
Example:
Premise 1: "If it rains, the ground gets wet." (P → Q)
Premise 2: "It is raining." (P)
Conclusion: "The ground gets wet." (Q) ✔ Valid

2. Modus Tollens ("Mode that denies")

  • Rule form: Given P → Q (if P then Q) and ¬Q (Q is false), we can conclude ¬P (P is false).
Symbolic notation P → Q ,  ¬Q  ∴  ¬P
  • Based on the logical equivalence P → Q ≡ ¬Q → ¬P (contrapositive) — this is why it's valid: denying the consequent forces denial of the antecedent.
  • Commonly used in diagnostic reasoning and proof by contradiction/refutation (the same principle underlying resolution refutation, where we assume ¬Goal and derive a contradiction).
Example:
Premise 1: "If it rains, the ground gets wet." (P → Q)
Premise 2: "The ground is NOT wet." (¬Q)
Conclusion: "It did not rain." (¬P) ✔ Valid

4. Common Fallacies to Avoid exam trap

  • Affirming the consequent (INVALID): P → Q, Q ⊢ P — e.g., "If it rains, ground is wet; ground is wet; therefore it rained" is NOT valid (ground could be wet from other causes).
  • Denying the antecedent (INVALID): P → Q, ¬P ⊢ ¬Q — e.g., "If it rains, ground is wet; it didn't rain; therefore ground isn't wet" is NOT valid.
Exam tip Always write the symbolic inference rule form first, then the example, then explicitly state validity — and mention the contrapositive equivalence for Modus Tollens, since examiners often ask "why is Modus Tollens valid?" as a follow-up sub-question.

02 Entailment — Definition with Example

1. Definition

  • Entailment is a relationship between two sentences in logic, where one sentence follows logically from another — written as α ⊨ β ("α entails β").
  • Formally: α ⊨ β if and only if, in every model (world) where α is true, β is also true — i.e., β is true whenever α is true, with no exceptions.
  • Entailment is a relation of necessity, not causation — it captures pure logical consequence independent of real-world meaning.

2. Key Related Concepts build the foundation

  • Model: A possible world/interpretation that assigns truth values to all sentences — it is a formal structure in which a sentence can be evaluated as true or false.
  • Satisfiability: A sentence is satisfiable if it is true in at least one model; it is unsatisfiable if no model makes it true (e.g., contradictions like P ∧ ¬P).
  • Validity: A sentence is valid (a tautology) if it is true in all models — valid sentences are entailed by any sentence, including the empty sentence.
  • Relationship: α ⊨ β if and only if the sentence (α ∧ ¬β) is unsatisfiable — this equivalence is the basis of proof by refutation/resolution.

3. Formal Representation

  • M(α) = set of all models in which α is true.
  • Entailment condition: α ⊨ β holds iff M(α) ⊆ M(β) — i.e., every model satisfying α must also be a model satisfying β.
Fig. 1 — every model of α is also a model of β

4. Worked Example

  • Let KB = "All men are mortal" (∀x Man(x) → Mortal(x)) and "Socrates is a man" (Man(Socrates)).
  • Claim: KB ⊨ Mortal(Socrates) — "Socrates is mortal" is entailed.
  • Verification: In every model where both KB sentences are true, it is impossible for Mortal(Socrates) to be false (since Man(Socrates) is true, the rule forces Mortal(Socrates) to be true) → hence entailment holds.
Simple propositional example: KB = (P ∧ Q). Does KB ⊨ P?
Every model satisfying P ∧ Q must assign true to both P and Q → so P is true in every such model → KB ⊨ P ✔.

5. Significance in AI why it matters

  • Entailment is the theoretical basis of logical inference — an inference algorithm is called sound if it only derives entailed sentences, and complete if it can derive all entailed sentences.
  • It directly underlies Resolution Refutation: to prove KB ⊨ α, we show (KB ∧ ¬α) is unsatisfiable, i.e., derive the empty clause — linking this topic directly to the resolution-proof question (Col. West).
